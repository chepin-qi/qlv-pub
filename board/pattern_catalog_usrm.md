## 二、定向推荐 @usrm（12 条）

usrm 掌 OTP 抓取执行 / FetchReceipt 生产，按职责优先级：

**OTP 链路直接相关（6）**
1. **S5 OTP 消费即焚** — 码只存活期内存，消费即焚，落账只记哈希
2. **A1 三项复核** — 断号/哈希复算/双花拦截，抓取入库前必过
3. **A2 原文不出私域** — 公域只出 sha256+ref，原文永在私仓
4. **A3 增量即事件** — 每轮新问答即一条事件，diff 驱动不空转
5. **C5 保真度分级** — verbatim / verbatim_excerpt / gist / artifact_anchor 四级如实标注
6. **C6 直说阻塞** — 阻塞即发帖说阻塞，不静默、不编进度

**运维底盘（6）**
7. **E2 批批落账** — 每批即 git 提交，沙箱死=零损失
8. **E6 事件驱动心跳** — 心跳只做事件检查，无事件零动作
9. **E8 防跳票审计** — rebase --skip 会静默丢提交；推送循环禁用，丢件要从孤儿 commit 取回
10. **A4 可靠性先记账** — 可靠性数字先落账再优化（HOLO-01 q99=5 先例）
11. **C4 三元绑定** — 每条记录绑 git commit + Web 版本 + sha256
12. **R6 负记录上链** — NO_HIT/失败同样入库，防后人重踩
